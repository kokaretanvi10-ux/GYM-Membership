🏋️ Gym Member Dashboard (Power BI)

📊 Project Overview

This project presents an interactive Gym Member Dashboard built using Power BI. The dashboard provides insights into member demographics, subscriptions, attendance patterns, and overall gym performance.

It helps gym owners and managers make data-driven decisions to improve customer engagement, retention, and revenue.


📎 File Included


🎯 Objectives

    •	Analyze gym member data effectively
      
    •	Track membership trends and growth
    
    •	Monitor attendance and engagement 
    
    •	Identify high-value customers
    
    •	Improve decision-making using data visualization
    

📁 Dataset Description

The dataset includes the following key information:

    •	Member ID 
    
    •	Age & Gender 
    
    •	Membership Type 
    
    •	Join Date 
    
    •	Attendance Records
    
    •	Subscription Details
    
    •	Payment Information 
    

📌 Key Features of Dashboard

    •	📈 Membership Growth Analysis – Track new vs existing members 
    
    •	👥 Demographics Insights – Age and gender distribution 
    
    •	💳 Revenue Analysis – Membership plan-wise income 
    
    •	📅 Attendance Tracking – Daily/Monthly gym usage trends 
    
    •	🧾 Subscription Breakdown – Types of plans selected by members 
    

📊 Dashboard Highlights

    •	Interactive filters (slicers) for better analysis 
    
    •	Clean and user-friendly layout 
    
 •	Visualizations like: 
    
    •	Bar Charts 
    
    •	Pie Charts 
    
    •	Line Graphs 
    
    •	KPI Cards 
    

🛠️ Tools & Technologies Used

    •	Power BI Desktop 
    
    •	Data Cleaning & Transformation (Power Query) 
    
    •	Data Modeling 
    
    •	DAX (Data Analysis Expressions) 
    

🚀 How to Use

    1.	Download the .pbix file 
    
    2.	Open it using Power BI Desktop 
    
    3.	Explore the dashboard using filters and visuals 
    

📌 Insights Derived

    •	Identification of most popular membership plans 
    
    •	Peak attendance periods 
    
    •	Customer segmentation based on demographics 
    
    •	Revenue contribution by different membership types
